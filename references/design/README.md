# Fluorite Labs — Visual Reference

## Canonical Hero Reference

Arquivo:

`fluorite-labs-hero-reference.webp`

Esta imagem é a referência visual canônica da experiência pública da Fluorite Labs.

Ela deve orientar:

- composição;
- proporções;
- hierarquia;
- escala;
- espaço negativo;
- relação entre texto e fluorita;
- iluminação;
- atmosfera;
- densidade;
- microtipografia;
- direção artística.

A implementação pode adaptar conteúdo textual, navegação, estados e responsividade conforme os documentos canônicos em `/docs`.

A implementação **não pode reinterpretar a linguagem visual da referência**.

Quando houver conflito:

1. decisões canônicas em `/docs`;
2. esta referência visual;
3. decisão local de implementação.

Uma implementação funcionalmente correta, mas visualmente fora desta direção, não é considerada concluída.

> Observação: este arquivo versionado é uma cópia otimizada da referência aprovada para consulta rápida no repositório. Os documentos 03, 04, 08, 09 e 10 definem os gates de fidelidade visual e validação.
